# Author your project.faf

`project.faf` is your project's context DNA — one file every AI tool can read,
in the IANA-registered `.faf` format.

**FAF: Initialize project.faf** authors a starter file from what your repo
already declares (`package.json`, lockfiles, framework config). It runs the
bundled FAF CLI on VS Code's own Node — no install, no network.

From there you fill the gaps and the score climbs.
